# Surface brief: apps/web（JobsWorld 工作台）

Scope: 整个 apps/web（世界、人物、软件报告、Study/Session、人工接管）。Visitor mode: Operate（世界页偏 Experience）。
Audience/job: 产品负责人与团队在局域网里复盘「软件到底怎么样」、围观模拟人正在用软件、了解人群。
Content: 全部来自 /api/v1 的真实数据；不编造指标。约束：无说明性小字；PlutoKeating design system；中英双语。
FORM: 街道作导航（surface roll seed:47836745e72b75df，dealt 4/7/3，lead 4；用户目标要求不暂停，故未开决策页）。挑战方案「车站出发看板」并入「此刻」列表的行内重排与变化高亮。

## Direction contract
THESIS: 城市就是导航。每一页底部常驻一条侧视像素街道（同一份 town 布局），人物实时在上面走；点建筑进地点、点人进人物。拒绝「左侧栏 + KPI 卡片墙」的后台模板。
OWN-WORLD: PlutoKeating 暖炭黑底（#0e0f11/#17181c）+ 琥珀 #f0a35e 只用于「此刻发生的事」与选中态；石板灰绿 #7d8f8a 做次要数据；Inter + 思源黑体；像素块（crispEdges）只出现在城市与头像，界面本身是干净的细线与 10px 圆角。
STORY: 打开即看到这座城此刻的时间、谁在哪、谁正在用哪个软件；向上是三个房间：人、软件、评测。
FIRST VIEWPORT: 世界页=整幅城市画布 + 右侧出发看板式的「此刻」列表（行原地重排，变化行保持琥珀高亮）；点人物弹出人物卡（正在做/在想/刚才/接下来）。
SIGNATURE: 底部街道地平线跨页常驻、点人物从街道直接打开人物卡；人物气泡实时冒出。
RISK: 像素画布在小屏可读性；以横向拖动与缩放应对。
