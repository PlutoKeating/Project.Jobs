# 调研资料：出游与聚餐

本目录放社会调研团队交来的原始资料，以及它们怎样用进了 JobsWorld 居民的人设。

| 文件 | 内容 |
|---|---|
| `出游聚餐调研_公开_20261115.xlsx` | 小红书出游与聚餐调研，第一阶段证据整理，批次 B20261115-01，采集日期 2026-11-15。14 个工作表：研究说明、关键词库、帖子明细、评论与回复、六类分类索引、负面诉求、要素分析（待分析）、推荐经验、避雷经验、出游专项（待分析）、吃饭专项（待分析）、统计与质控、交接待核线索、公开检索候选 |

## 1. 这份资料是什么、不是什么

- **是**：一个平台（小红书）上、10 个已执行检索词下，人工读过的 11 个来源帖（8 篇文字正文已核验、3 篇只读了部分）、73 条相关评论、35 条不开心经历与诉求（28 个事件组）、31 条网友推荐的办法、8 条避雷办法。每条都有帖子/评论编号，可回查原帖。
- **不是**：市场调研或发生率估计。没有竞品、产品功能、价格或用户规模的数据；第二阶段的分析表（`06_要素细节分析`、`09_出游专项分析`、`10_吃饭专项分析`）都还是「待分析」；样本内的数量不代表全平台比例（研究说明里也这样写明）。
- **覆盖面**：六类里「吃饭与聚餐」「吃饭避雷」最充实（11 帖中 7 帖涉及吃饭）；**以小时计的本地活动**有一些（周末一个人逛馆、和不熟的人吃饭、室友聚餐 AA、停车费）；**以天或周计的异地旅行**很薄：只有一篇三天周边游的文字正文（P0002），一篇日本 12 天旅行只读了评论、视频没看完（P0003），一条评论提到十天的长途（C0018）。目的地怎么选、预算、交通和住宿怎么订、节假日人多、天气，都还没有证据。
- **样本偏差**：只有中文平台；广州样本偏多（P0004、P0007、P0011）；评论集中在少数几个帖子（P0001 一帖贡献 17 条）。英语区居民没有任何直接证据。

## 2. 检查结论

逐表核对了计数、编号关联与口径。**内部数字是对得上的**：11 个来源帖、73 条评论（实际读取 146 条，与各帖之和一致）、35 条诉求、六类的原帖映射数与评论映射数都与 `00_研究说明` 一致；`03` 的分类列与 `04` 的映射一致；每条评论的父评论、回复目标都存在。

## 3. 用进了人设的哪里

居民的人设新增第七层 `leisure`「出门与吃喝玩乐」（`PersonaSpecSchema`，`packages/core/src/types/domain.ts`）。随包的 185 位居民由规则推导（`packages/engine/src/human/leisure.ts`，词表 `config/population/leisure.json`），14 位手写人物（`config/personas/`）按各自的生平手写。每个人的 `leisure.sources` 记下用到的调研编号。

| 维度 | 取值 | 怎么定的 | 依据 |
|---|---|---|---|
| 本地活动（以小时计） | 做什么、一次几小时、一个月几次、和谁 | 爱好 + 节奏；同伴只取本地的家人和熟人圈子 | P0004、C0028、C0030、C0037、C0039 |
| 出远门（以天/周计） | 不出 / 周边 / 国内 / 国内外，一年几次，每次几天，和谁 | 预算 + 年龄 + 收入 | P0002、P0003、C0018（证据薄，主要是常识） |
| 同行角色 | 拿主意 / 一起商量 / 跟着走 / 多半自己去 | 有条理又外向 → 拿主意；随和而不操心 → 跟着走；内向、爱新鲜、独居 → 自己去 | C0011、C0017；C0007、C0008；C0009、C0013、C0023；C0001、C0005 |
| 定方案时 | 提前说 / 都可以 / 被否多了不再提 / 嘴上随便、事后挑 | 内向又敏感 → 不再提；不随和也不操心 → 事后挑；很随和 → 都可以 | C0003、C0004、C0005、P0002 |
| 节奏 | 一天跑好几处 / 不紧不慢 / 慢慢逛、放空 | 外向、情绪稳定、爱新鲜、年轻、不累 → 快 | P0002、P0004、H002（待核） |
| 社交电量 | 0–1 | 外向性为主 | C0018、P0006 |
| 钱 | 能省则省 / 要花得值 / 舒服优先 / 不太看价钱；AA 算清 / 大致 AA / 轮流请 / 常替大家垫 | 价格敏感度 + 收入；很随和又不太在乎钱 → 常垫 | P0009、C0062–C0067 |
| 出行 | 走路骑车 / 地铁公交 / 打车 / 开车 | 城市层级、收入、年龄、家里有没有孩子；美国大城市以外多开车 | P0011、C0070–C0073 |
| 吃饭 | 忌口、怎么选店、一个人吃自不自在、最受不了什么 | 爱比较 → 看点评（会被照片和参考人均坑）；忌口按比例抽 | P0005、P0007、P0008、P0010、C0016、C0045、C0050、C0052、C0055、C0057–C0060、C0069、H003（待核） |
| 一起出去最怕 | 2 条 | 按角色、节奏、电量、分账方式挑 | P0002、C0002、C0004、C0005、C0007、C0008、C0011、C0012、C0017、C0018 |
| 吃过亏后的做法 | 2 条（网友提出的办法，未验证效果） | 同上 | C0001、C0003、C0006、C0010、C0013、C0015、C0016、C0019、C0022、C0023、C0026、C0034、C0038、C0039、C0040、C0062、C0065、C0066、C0071–C0073、P0006 |
| 往事 | 2–3 件第一人称的经历，落到这个人自己的家人、熟人和去过的地方 | 同上；进记忆树的 `past` 分支（钉住，不随整理遗忘，见 `packages/memory`） | 见下方编号 |

几点约束：

- **数值不由模型定**：沿用人口合成的原则（`population.ts`），由性格、价格敏感度、收入、年龄、家庭推导，加以人物 id 为种子的小扰动；同一个人每次推导结果相同。
- **调研里的数量不变成比例**：例如「被否多了不再提」只来自一条评论（C0004），推导时按性格条件触发，不代表人群里有多少这样的人。
- **英语区居民**：调研没有英语区样本。同样的机制（谁拿主意、事后挑、AA 拖欠、停车费）用当地的说法套用，属于迁移，不是证据。
- **儿童**：没有调研依据，`sources` 为空，只写跟家人出去的日常。
