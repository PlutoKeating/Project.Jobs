发布之前，先让一座城的人用用看。

把网址交给 Jobs。JobsWorld 里住着两百个各不相同的人：他们过着自己的日子，在应用商店、广告和朋友口中遇到你的产品，自己决定看不看、用不用、留不留、跟谁说。

curl -fsSL https://jobs.plutokeating.beer/install | bash

需要一台装了 Docker 的机器。装好后打开网页，接入你自己的模型供应商。先看看这个脚本做什么

怎么用

  1. 发布

    粘贴网址、名字、一句话。本机上的开发服务器也行。

  2. 他们自己决定

    没有人被指派去测试。地铁上单手拿着手机的人、带着孩子的人、只剩五分钟的人，各自遇到它，各自决定点不点开。用的时候他们只看得到屏幕。

  3. 读一页人话

    好不好用，哪里最让人难受，谁会留下谁会走，看到的人为什么没点开，最该改的一件事。每一句都能点开看是谁说的、原话和当时的屏幕。

也在终端和 coding agent 里

写完代码就发布，取回结论和带复现步骤的问题清单，接着改。同一座城还能用 Terraria 走进去，或者接到飞书里。

# 发布、看状况、要结论
jobsworld publish http://127.0.0.1:3000/ \
  --name 闪念笔记 --tagline "想到什么，马上记下"
jobsworld status 闪念笔记
jobsworld report 闪念笔记 --eng

# 接进 Claude Code（其他支持 MCP 的 agent 同理）
claude mcp add jobs -- jobsworld mcp

装在哪、谁的模型、什么许可证

  • 装在你自己的机器上

    居民、记忆、截图和结论都存在你机器上的 Docker 卷里，不经过我们的服务器。

  • 模型由你接入

    在网页里选供应商、粘贴 Key、勾选模型。花了多少，页头一直显示。

  • 开源

    以 AGPL-3.0 发布，源码在 GitHub。
